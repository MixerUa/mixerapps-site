# mixerapps.dev

Website of MixerApps — apps by Oleksandr Mykusevych.

## Как устроен сайт (простыми словами)

Сайт — это обычные HTML-файлы, без программ-сборщиков. Что лежит в файле, то и показывается в браузере.
GitHub Pages сам публикует сайт через 1–2 минуты после каждого изменения в этом репозитории.

| Файл | Что это |
|---|---|
| `index.html`, `about.html`, `contact.html` | английские страницы: главная, «О разработчике», «Контакты» |
| `ru/…` | те же страницы на русском |
| `assets/css/style.css` | оформление (цвета, шрифты, отступы) — одно на весь сайт |
| `assets/img/` | картинки, уменьшенные для сайта |
| `assets/originals/` | исходные картинки в полном размере (резервная копия) |
| `CNAME` | адрес сайта `mixerapps.dev` — не удалять |
| `404.html` | страница «не найдено» |

Чтобы поменять текст: откройте нужный файл на github.com → значок карандаша → исправьте текст →
кнопка «Commit changes». Английскую и русскую версию нужно править обе.

Юридические страницы Tenora живут отдельно (`mixerua.github.io/tenora-legal`) и здесь только упоминаются ссылками —
их адрес внесён в Google Play Console, переносить нельзя.
